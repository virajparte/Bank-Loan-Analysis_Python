# Bank Loan Analysis

## Project Overview
Analyzed financial loan data using Python to understand lending trends, loan performance, repayment amounts, and borrower characteristics.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Key Performance Indicators
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income (DTI) Ratio
- Good Loan and Bad Loan Analysis

## Exploratory Data Analysis
1. Monthly lending trends by issue date
2. State-wise loan application analysis
3. Loan term distribution
4. Employment length analysis
5. Loan purpose breakdown
6. Home ownership analysis
7. Good loan versus charged-off loan analysis

## Key Findings
- Analyzed 38,576 loan records.
- Evaluated loan application trends and funding activity.
- Compared loan performance across terms, states, employment lengths, and loan purposes.
- Identified differences in charged-off rates across borrower and loan categories.

## Project File
`Bank_Loan_Analysis.ipynb`

## Objective
To extract actionable insights from loan data and support data-driven lending and credit-risk analysis.
